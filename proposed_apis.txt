================================================================================
 TRIPNOVA - PROPOSED API SPEC (v2)
 So sánh & mở rộng từ 1.pdf, đối chiếu schema Postgres hiện có
 Convention:
   - Base: /api
   - Không dùng trailing slash
   - Pagination:  ?page=0&size=20&sort=field,asc|desc   (Spring Data style)
   - List trả header: X-Total-Count
   - Auth: JWT Bearer trong header Authorization
   - Content-Type: application/json (upload: multipart/form-data)
   - Error body: { "timestamp", "status", "error", "message", "path", "traceId" }
   - HTTP status theo PDF (200/201/204/400/401/403/404/409/500) + 422 (validation)
================================================================================

Ký hiệu:
  [OK]     = đã có trong code
  [KEEP]   = giữ từ PDF, không đổi
  [FIX]    = có trong PDF nhưng sửa path/method cho đúng chuẩn
  [NEW]    = đề xuất thêm (DB đã hỗ trợ hoặc là hạ tầng chuẩn)
  [ADMIN]  = yêu cầu role ADMIN
  [AUTH]   = yêu cầu đăng nhập

 III. TỔNG KẾT
================================================================================
- Đã có (khớp PDF): 11 endpoint (Hotel 4, Destination 4, Landmark 1, Country 2 - bonus).
- Đề xuất TOTAL: ~230 endpoint (Public ~110, Admin ~120).
- Đề xuất mới ngoài PDF: tách Favorites, Reviews, Posts/Comments,
  Itineraries, Notifications, Uploads, Search, AI (chat/recommend/predict),
  Refunds, Invoices download, OAuth accounts, Bulk availability,
  Roles/Permissions management, Audit logs.
- Sửa PDF: bỏ prefix `/api` cho OAuth, đổi confirm-payment thành webhook,
  cancel booking dùng POST thay DELETE, chuẩn hoá bỏ trailing slash.
